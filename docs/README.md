# MarketData Provider documentation

Canonical documentation for the MarketData Provider 4.0.0 release line.

## Documents

| File | Purpose |
|---|---|
| `ARCHITECTURE.md` | Package responsibilities, hardening layout, and exchange-registry boundary. |
| `EXCHANGES.md` | Native adapters, planned exchange metadata, canonical market types, and adapter policy. |
| `DEVELOPMENT.md` | Local checks, CLI smoke commands, and exchange registry checks. |
| `RELEASE_4_0.md` | Release scope, gate commands, final hardening notes, and registry CLI notes. |

## Reading order

Start with `ARCHITECTURE.md`, then read `EXCHANGES.md` before changing adapters or market-type metadata. Use `DEVELOPMENT.md` and `RELEASE_4_0.md` for validation and release work.
